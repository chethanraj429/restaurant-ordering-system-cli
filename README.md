# Restaurant Ordering System (Python CLI)

A command-line restaurant ordering system built using Python.

## Features

- Display menu
- Order veg and non-veg items
- Multiple item ordering
- Bill generation
- Functions for modular code
- Input validation

## Technologies

- Python
- Dictionaries
- Lists
- Functions

## Future Improvements

- JSON-based menu
- File handling
- Quantity support
- Order history
- Admin menu
